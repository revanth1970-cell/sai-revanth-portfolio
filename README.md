# Sai Revanth — Developer Portfolio

A responsive personal portfolio built with semantic HTML5, CSS3 and vanilla JavaScript (ES6). The site highlights ServiceNow learning projects, web development skills and professional experience.

## Features

- Mobile-first responsive layout using CSS Grid and Flexbox
- Dark/light theme toggle (saved in `localStorage`)
- Responsive hamburger navigation
- Smooth in-page navigation
- Project detail modal popups
- Accessible labels, focus handling and reduced-motion support
- No build step or framework required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, use the VS Code Live Server extension or run:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Personalize before publishing

Search the project for `YOUR_EMAIL@example.com` and `YOUR_GITHUB_USERNAME`, then replace them with your real details. Review the LinkedIn URL and update it if needed.

Optional:
- Add your resume as `assets/resume.pdf` and add a Resume link to the navigation or hero section.
- Add links to public GitHub repositories for each project after you publish them.
- Add project screenshots only when you have genuine screenshots of your own work.
- Verify the project descriptions and skills reflect what you have personally completed.

**Accuracy note:** The ServiceNow cards are presented as training/practice projects, not paid client work or production deployments. HUDL is listed separately as professional experience.
